# Live bringen & aufs iPad – Kurzanleitung

## 1. Repo öffentlich machen (einmalig)

GitHub Pages ist mit einem kostenlosen GitHub-Konto nur für **öffentliche** Repos verfügbar, und dein Repo ist privat.

GitHub → Repo **English-Game** → **Settings** → **General** → ganz unten „Danger Zone“ →
**Change visibility** → **Public**.

Im Code stehen keine persönlichen Daten. Name und Fortschritt deines Sohnes werden nur auf dem iPad gespeichert.

> Soll das Repo privat bleiben, gibt es zwei Möglichkeiten: GitHub Pro (ca. 4 $/Monat)
> oder [Netlify Drop](https://app.netlify.com/drop), wo man den Ordner einfach per Drag & Drop hochlädt.
> Bei Netlify Drop musst du nach jeder Änderung neu hochladen.

## 2. GitHub Pages einschalten

**Settings** → **Pages** → bei „Source“ **Deploy from a branch** wählen →
Branch **`main`**, Ordner **`/ (root)`** → **Save**.

Nach 1–2 Minuten ist die App online unter:
**https://ckurtzmann-maker.github.io/English-Game/**

Diese Adresse erst am Computer öffnen und prüfen, ob die App lädt.

## 3. Aufs iPad

1. Adresse in **Safari** öffnen.
2. Teilen-Symbol (□↑) → **Zum Home-Bildschirm** → **Hinzufügen**.
3. Ab jetzt **immer über das Flugzeug-Icon** starten, nicht über Safari.
   Safari und das Icon speichern den Fortschritt getrennt.
4. Auf ▶ tippen. Beim ersten 🎤 im Papagei-Spiel das Mikrofon **erlauben**.

## 4. Einrichten (2 Minuten)

- **Eltern-Bereich:** das ⚙️ oben rechts **1,5 Sekunden gedrückt halten**. Dort den Namen eintragen
  und das Abflugdatum prüfen.
- **Bessere Stimme (lohnt sich sehr):** iPad-Einstellungen → Bedienungshilfen → Gesprochene Inhalte →
  Stimmen → Englisch → **Samantha (Erweitert)** oder **Ava (Premium)** laden.
  Danach im Eltern-Bereich unter „Englische Stimme“ auswählen und testen.
- **Optional, damit er nicht aus der App rauswischt:** Einstellungen → Bedienungshilfen →
  **Geführter Zugriff** einschalten. In der App dann dreimal die obere Taste drücken → Start.

## 5. Gut zu wissen

- **Kein Ton?** Lautstärke hochdrehen und im Kontrollzentrum prüfen, dass das iPad nicht stummgeschaltet ist (🔕).
- **Für den Flug:** Die App vor dem Abflug einmal mit Internet öffnen. Danach läuft sie offline.
- **Nach einer Änderung am Code:** App komplett schließen (hochwischen) und neu öffnen, notfalls zweimal.
  Die neue Version lädt automatisch.
- **App-Icon nicht löschen.** Sonst sind Sterne und Sticker weg.
